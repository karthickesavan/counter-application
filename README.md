# Counter Application

A React counter project for practising the `useState` hook.

## Features
- Increment the count by 1
- Decrement the count by 1 without going below zero
- Reset the count to zero
- Conditionally display **Minimum limit reached** at zero
- Responsive styling and accessible status updates

## Run locally
1. Install Node.js.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm start`.
5. Open the local URL shown in the terminal (usually http://localhost:3000).

## useState concept
The initial state is set with `const [count, setCount] = useState(0);`.
The functional update form ensures each change uses the latest state.
